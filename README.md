# personal-Resume

静态个人主页 / 简历站点，用 HTML + CSS 写成。页脚署名为 lyn。

## 页面

| 文件 | 内容 |
|------|------|
| `index.html` | 首页介绍 |
| `html/home.html` | Home |
| `html/about.html` | 关于我 |
| `html/server.html` | 兴趣 |
| `html/success.html` | 教育 |
| `css/` | 样式 |
| `img/` | 图片 |

## 本地打开

直接用浏览器打开 `index.html` 即可，不需要构建工具。

```bash
start index.html
```
